01

Variáveis, tipos e condicionais

Aula 1▶
Objetivo: declarar variáveis dos tipos básicos, converter entre tipos e controlar o fluxo do programa com if/elif/else.

Conteúdo

  • Variável é um rótulo pra um valor — Python infere o tipo (tipagem dinâmica). Tipos: int, float, str, bool.
  • Conversão explícita com int(), float(), str(). Operadores aritméticos, de comparação e lógicos.
  • if / elif / else — a indentação (4 espaços) define o bloco, não chaves.

Exemplo resolvido

Classificar a altitude de um satélite:

altitude_km = 408
em_orbita = altitude_km > 160  # bool: True

if em_orbita and altitude_km < 2000:
    print("Órbita baixa (LEO)")
elif em_orbita:
    print("Órbita alta")
else:
    print("Ainda em ascensão")
# saída: "Órbita baixa (LEO)"

Repare que em_orbita guarda o resultado de uma comparação — já é um bool, não precisa reescrever a condição.

Exercícios
1.1 Classifique um IMC (peso / altura**2) em "abaixo do peso" (<18.5), "normal" (18.5–24.9), "sobrepeso" (25–29.9) ou "obesidade" (≥30).
ver solução 
peso, altura = 68, 1.70
imc = peso / altura ** 2
if imc < 18.5: categoria = "abaixo do peso"
elif imc < 25: categoria = "normal"
elif imc < 30: categoria = "sobrepeso"
else: categoria = "obesidade"
print(f"IMC {imc:.1f} → {categoria}")
1.2 — pegadinha O que "10" + "5" retorna? E int("10") + int("5")? Por que Python não deixa somar "10" + 5 direto?
ver solução

"10" + "5" → "105" (concatenação). int("10") + int("5") → 15. Python não converte str+int automaticamente porque seria ambíguo (somar ou concatenar?) — dá TypeError.

02

Funções e loops

Aula 2▶
Objetivo: criar funções reutilizáveis e repetir tarefas com for e while.

Conteúdo

  • def nome(parametros): ... return. Sem return, devolve None.
  • lambda x: x*2 — função anônima, útil com sorted(key=...).
  • while repete até a condição falhar; for itera sobre sequências; break/continue controlam o fluxo.

Exemplo resolvido

def calcular_velocidade_orbital(altitude_km, g=6.674e-11, massa=5.972e24):
    raio = (6371 + altitude_km) * 1000
    return (g * massa / raio) ** 0.5 / 1000

for alt in [200, 408, 800]:
    v = calcular_velocidade_orbital(alt)
    print(f"{alt} km → {v:.2f} km/s")
Exercícios
2.1 Ordene satelites = [("Amazonia-1", 752), ("CBERS-4", 645), ("SGDC-1", 35786)] pela altitude usando lambda + sorted().
ver solução 
satelites = [("Amazonia-1", 752), ("CBERS-4", 645), ("SGDC-1", 35786)]
ordenado = sorted(satelites, key=lambda s: s[1])
print(ordenado)
2.2 Escreva uma função contar_passagens(dias, intervalo_horas) usando while que conta quantas passagens de satélite ocorrem em N dias, se ele passa a cada intervalo_horas.
ver solução 
def contar_passagens(dias, intervalo_horas):
    horas_totais = dias * 24
    passagens, horas_passadas = 0, 0
    while horas_passadas + intervalo_horas <= horas_totais:
        horas_passadas += intervalo_horas
        passagens += 1
    return passagens

print(contar_passagens(7, 6))

Strings e arquivos

04

Listas, dicionários e tuplas

Aula 4▶
Objetivo: escolher a estrutura de dados certa pra cada problema.

Conteúdo

  • Listas []: ordenadas, mutáveis. Dicts {}: chave→valor, use .get(chave, padrao). Tuplas (): imutáveis, usadas como chave de dict (listas não podem — não são hashable).
  • List comprehension: [x**2 for x in range(5) if x % 2 == 0].

Exemplo resolvido

estacoes = [{"nome": "Manaus", "pm25": 18.4}, {"nome": "Alta Floresta", "pm25": 42.1}]
acima_limite = [e["nome"] for e in estacoes if e["pm25"] > 25]
print(acima_limite)  # ['Alta Floresta']
Exercícios
4.1 Dada temperaturas = [22.1, 24.5, 19.8, 30.2, 27.7], gere uma lista só com valores acima de 25 e outra convertida pra Fahrenheit.
ver solução 
temperaturas = [22.1, 24.5, 19.8, 30.2, 27.7]
acima_25 = [t for t in temperaturas if t > 25]
fahrenheit = [t * 9/5 + 32 for t in temperaturas]
4.2 Por que uma lista não pode ser chave de dicionário, mas uma tupla pode?
ver solução

Chaves de dict precisam ser hashable (hash fixo). Listas são mutáveis — se o conteúdo mudasse, o hash ficaria inconsistente. Tuplas são imutáveis, então servem.

05

Pandas — Series e DataFrames

Aula 5▶
Objetivo: carregar, filtrar e agregar dados tabulares com Pandas.

Conteúdo

  • .loc[] seleciona por rótulo; .iloc[] por posição — depois de um filtro, o índice pode não ser sequencial e os dois retornam linhas diferentes.
  • .query() filtra; .groupby().agg() agrega; pd.merge() combina tabelas.

Exemplo resolvido

df = pd.DataFrame({"estacao": ["A","A","B"], "pm25": [30.2, 28.1, 15.4]})
media_por_estacao = df.groupby("estacao")["pm25"].mean()
acima = df.query("pm25 > 20")
Exercício
5.1 Qual a diferença prática entre .loc[] e .iloc[]? Dê um exemplo em que eles retornam coisas diferentes no mesmo DataFrame.
ver solução

Se o índice do DataFrame não for sequencial (ex: sobrou [2, 5, 7] após um filtro), df.loc[2] pega a linha rotulada "2", enquanto df.iloc[2] pega a terceira linha física — podem ser linhas completamente diferentes.

06

Classes e herança (POO)

Aula 5▶
Objetivo: modelar dados e comportamento com classes, e reaproveitar código com herança.

Conteúdo

  • __init__(self, ...) é o construtor. class Filha(Mae): herda; super().__init__() chama o construtor da mãe.

Exemplo resolvido

class Sensor:
    def __init__(self, nome, unidade):
        self.nome = nome
        self.unidade = unidade
        self.leituras = []
    def media(self):
        return sum(self.leituras) / len(self.leituras) if self.leituras else 0

class SensorTemperatura(Sensor):
    def __init__(self, nome):
        super().__init__(nome, unidade="°C")
    def em_fahrenheit(self):
        return self.media() * 9/5 + 32
Exercício
6.1 O que super().__init__() faz, e por que esquecê-lo numa subclasse costuma causar bug?
ver solução

Garante que os atributos definidos na classe-mãe (self.nome, self.unidade...) sejam criados na instância. Sem isso, esses atributos não existem — qualquer método herdado que dependa deles quebra com AttributeError.

07

NumPy

Aula 5▶
Objetivo: operar arrays numéricos de forma vetorizada, sem loops explícitos.

Conteúdo

  • Array homogêneo, operações vetorizadas — muito mais rápido que loop Python puro (código C, blocos contíguos de memória).
  • "Band math" em imagens de satélite: operar arrays inteiros sem loop — ex: NDVI = (nir - red)/(nir + red).

Exemplo resolvido

nir = np.array([[0.45, 0.50], [0.40, 0.55]])
red = np.array([[0.10, 0.12], [0.09, 0.14]])
ndvi = (nir - red) / (nir + red)
print("Vegetação saudável:", (ndvi > 0.5).sum(), "pixels")
Exercício
7.1 Por que operar com arrays vetorizados é mais rápido que um for pixel a pixel?
ver solução

NumPy roda em código C compilado sobre memória contígua (SIMD, cache). Um for em Python reavalia tipo e faz overhead de interpretador a cada iteração — em imagens com milhões de pixels, isso é ordens de magnitude mais lento.

09

Shapely — geometrias

python_gis_0▶
Objetivo: criar e comparar geometrias vetoriais seguindo o padrão OGC.

Conteúdo

O Simple Features (OGC, ISO 19125) é o padrão que a Shapely implementa: Point, LineString, Polygon e versões "Multi". Toda geometria tem .area, .length, .centroid, .bounds.

PredicadoMétodoSignificado
Equals.equals(B)Topologicamente iguais
Disjoint.disjoint(B)Nenhum ponto em comum
Intersects.intersects(B)Ao menos um ponto em comum
Touches.touches(B)Se tocam só na fronteira
Crosses.crosses(B)Se cruzam (dimensões diferentes)
Within.within(B)A completamente dentro de B
Contains.contains(B)A contém B
Overlaps.overlaps(B)Sobrepõem parcialmente

WKT (texto legível) e WKB (binário compacto, usado por PostGIS) são os formatos de troca. Operações de conjunto: .union(), .intersection(), .difference(), .symmetric_difference().

Exemplo resolvido

from shapely.geometry import Point, Polygon, box

area_protegida = Polygon([(-61,-4),(-59,-4),(-59,-2),(-61,-2)])
estacao = Point(-60.02, -3.10)
print(area_protegida.contains(estacao))  # True

A, B = box(2,2,6,6), box(4,4,8,8)
print(A.overlaps(B), A.intersection(B).area)
Exercícios
9.1 Crie um Polygon com um buraco (holes=) e teste se um ponto dentro do buraco é considerado "contido".
ver solução 
poligono_com_buraco = Polygon(
    [(0,0),(10,0),(10,10),(0,10),(0,0)],
    holes=[[(3,3),(7,3),(7,7),(3,7),(3,3)]]
)
print(poligono_com_buraco.contains(Point(5,5)))  # False — buraco não conta como "dentro"
9.2 .within() e .contains() são opostos? Explique.
ver solução

Sim. a.contains(b) ⟺ b.within(a) — a contém b é o mesmo que dizer que b está dentro de a.

11

CRS e projeções

ebook · week1▶
Objetivo: entender por que todo dado espacial precisa de um sistema de referência, e reprojetar corretamente.

Conteúdo

Assim como "10" não quer dizer nada sem unidade, uma coordenada não quer dizer nada sem um CRS.

A Terra é um elipsoide de revolução — cada ajuste regional gera um Datum diferente. Conversão = trocar projeção mantendo o datum (sem perda). Transformação = trocar de datum (pode introduzir metros de incerteza).

GeográficoProjetado
Unidadegraus (°)metros
ExemploWGS84 (EPSG:4326)SIRGAS2000/UTM (EPSG:319xx)

Nenhuma projeção existe sem distorção: PlateCarree não corrige nada, Mercator preserva ângulo, Mollweide/Albers preservam área. UTM usa 60 zonas de 6° — cada uma só é precisa perto do seu centro. SIRGAS2000 é o datum oficial do Brasil (compatível com WGS84 na prática).

Não existe área em graus. Sempre reprojete pra um CRS métrico (UTM) antes de medir área, distância ou fazer buffer.

Exemplo resolvido

import pyproj
transformer = pyproj.Transformer.from_crs("EPSG:4326", "EPSG:31982", always_xy=True)
x, y = transformer.transform(-48.5495, -27.5973)  # Florianópolis: graus → metros

area_graus = sc.geometry.area.iloc[0]                    # inútil
area_km2 = sc.to_crs(31982).geometry.area.iloc[0] / 1e6   # correto
Exercícios
11.1 Qual a diferença entre .set_crs() e .to_crs()?
ver solução

.set_crs() só declara qual CRS os dados já estão usando — não move nenhum ponto. .to_crs() converte as coordenadas de verdade, os valores numéricos mudam.

11.2 Pesquise o código EPSG UTM da sua região e reprojete um GeoDataFrame de teste. O que muda nos valores das coordenadas?
dica

Os valores deixam de estar em graus (~-23.55) e passam a estar em metros a partir de uma origem local (números na casa das centenas de milhares) — porque você saiu de um CRS esférico pra um plano.

12

H3 — grades hexagonais

ebook · week1▶
Objetivo: indexar uma área geográfica numa grade uniforme pra agregação espacial em escala.

Conteúdo

Grades quadradas têm distâncias desiguais entre vizinhos (ortogonal = 1, diagonal ≈1.41). H3 (Uber) usa hexágonos: os 6 vizinhos ficam sempre à mesma distância do centro — padrão da indústria pra precificação dinâmica e análise espacial em escala.

Exemplo resolvido

import geobr, h3
muni = geobr.read_municipality(code_muni=4205407, year=2020)  # Florianópolis
shape = h3.geo_to_h3shape(muni.geometry.iloc[0])
cells = h3.h3shape_to_cells(shape, 8)  # resolução 8 (~0.7 km²/hexágono)
Exercício (tarefa oficial do ebook)
12.1 Escolha uma cidade (Bonito/MS 5002308, Paraty/RJ 3303807, Lençóis/BA 2919207, Bento Gonçalves/RS 4302105), gere as células H3 em resoluções 7, 8 e 9, calcule uma métrica por célula (distância ao centro, por exemplo) e monte um mapa interativo com folium.
reflexão

Compare com um colega que escolheu outra cidade: o número de hexágonos muda muito entre cidade pequena e grande? A resolução 9 ainda é viável pra um município enorme?

Fiona

Conteúdo

Fiona faz interface com a OGR (parte vetorial da GDAL) — o GeoPandas usa Fiona por baixo dos panos. Uma feição (feature) = geometria + atributos. mapping() do Shapely converte geometria pro dict GeoJSON-like que a Fiona espera na escrita.

import fiona
with fiona.open("saida/pontos.shp") as src:
    print(src.driver, src.crs, len(src))

Quando você precisa de iteração eficiente sem carregar tudo em memória (arquivos enormes), controle fino sobre schema/campos ao escrever, ou acesso a formatos que o GeoPandas não suporta bem.

Spatial join

Conteúdo

ParâmetroOpçõesDescrição
how"inner", "left", "right"Tipo de join

escolas_por_bairro = gpd.sjoin(escolas, bairros_gdf, how="inner", predicate="within")

14.1 Qual a diferença entre usar predicate="within" e predicate="intersects" num sjoin de pontos em polígonos?

"within" só junta pontos totalmente dentro do polígono. "intersects" é mais permissivo — inclui pontos exatamente na fronteira também.

Overlay

python_gis_2▶
Objetivo: gerar novas geometrias a partir da sobreposição de duas camadas.

Conteúdo

howResultado
"intersection"Área comum às duas camadas
"union"Todas as áreas combinadas
"difference"Primeira camada excluindo a segunda

intersecao = gpd.overlay(zonas.iloc[[0]], zonas.iloc[[1]], how="intersection")

15.1 Explique a diferença fundamental de resultado entre sjoin e overlay.
ver solução

16

Buffer, convex hull e dissolve

notebook + ebook▶
Objetivo: criar zonas de influência, envoltórias convexas e agregações por atributo.

Conteúdo

Buffer cria uma zona de influência ao redor de uma geometria — sempre em CRS projetado (metros). Convex hull é o menor polígono convexo que contém todos os pontos. Dissolve une geometrias vizinhas que compartilham um atributo.

Buffer em CRS geográfico (graus) dá resultado distorcido — sempre reprojete antes.

Exemplo resolvido

buffers = escolas[["id","geometry"]].copy()
buffers["geometry"] = buffers.buffer(1000)  # 1 km, em CRS projetado

hull = escolas.geometry.union_all().convex_hull

bairros_dissolvidos = quadras.dissolve(by="bairro", aggfunc="sum")
Exercícios
16.1 Combine buffer + overlay(how="intersection") pra encontrar áreas cobertas por dois buffers de escola ao mesmo tempo.
ver solução 
pares = gpd.overlay(buffers, buffers, how="intersection")
pares = pares[pares["id_1"] < pares["id_2"]]  # evita duplicar A∩B com B∩A
cobertura_dupla = pares.union_all()
16.2 Por que dobrar o raio do buffer quase sempre mais que dobra o número de pares sobrepostos?
ver solução

A área de cada buffer cresce com o quadrado do raio (área ∝ r²) — dobrar o raio quadruplica a área, aumentando a chance de sobreposição de forma não-linear.

17

Topologia e distância na prática

ebook · Sinop▶
Objetivo: classificar pontos por relação espacial e calcular distâncias reais entre camadas.

Conteúdo

Relações topológicas são booleanas (tabela do Módulo 09). Relações de distância são contínuas — entre pontos é euclideana; entre ponto e polígono, é a distância mínima.

Exemplo resolvido

area_urbana = centro.buffer(5000).iloc[0]  # 5 km, em metros
schools["zona"] = np.where(schools.within(area_urbana), "urbana", "rural")

dist_para_saude = schools.geometry.apply(lambda pt: saude.distance(pt).min())

Transformações afins distorcem uma geometria sem recalcular nada a partir dos dados originais: shapely.affinity.rotate(geom, 45, origin="centroid").

Exercício
17.1 Por que .distance() entre um ponto e um polígono não é ambíguo, mesmo o polígono tendo "vários pontos"?
ver solução

Porque a definição é sempre a menor distância entre qualquer par de pontos das duas geometrias — não há ambiguidade, é um mínimo bem definido.

Exercício
18.1 Adicione ao resumo acima a distância mínima até a saúde mais próxima por zona.
